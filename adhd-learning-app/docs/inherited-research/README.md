# Agent Specifications

This folder contains all agent specifications, prompts, and configuration files.
**Files here represent human-authored instructions for agent behavior.**

## Purpose

Define *what* agents should do, what inputs they receive, and what counts as success.
Nothing in this folder is generated by an AI — everything here is written by a person.

## What belongs here

- Agent specifications (`*.md` files describing one agent's job)
- Prompts and prompt templates
- Orchestration specs (how multiple agents hand work to each other)
- Workflow definitions

## What does NOT belong here

- Generated code or agent outputs → those go in `/src`
- Tool configuration (`package.json`, `.gitignore`, `claude-flow.config.json`) → those go in the repo root
- Secrets or API keys → those go in `.env`, which is gitignored

## Convention

All files here are **version-controlled human inputs**. When you change a file in this
folder, the Git history shows a change in *intent* — what you asked for. That is
deliberately separate from `/src`, where the history shows changes in *output*.

## Specification template

Every agent spec should include these six parts:

```markdown
# [Agent Name]

## Objective
[One clear sentence: what does this agent do?]

## Context
[Background the agent needs — domain, terminology, why this matters]

## Input Contract
[Exactly what this agent receives, and in what format]

## Task Instructions
1. [Step-by-step process]
2. [Include verification steps]
3. [Include error handling]

## Output Contract
[Exact format of what this agent produces]

## Success Criteria
[3-5 measurable criteria — no vague words like "good" or "thorough"]

## Constraints and Guardrails
[Explicit list of what this agent should NOT do]
```

## Rules of thumb

- **Specify goals, not steps.** "Search for X using whatever interface exists" survives
  a redesign; "click `#search-icon`, wait 500ms" does not.
- **Delete vague words.** "comprehensive," "detailed," "professional," "high-quality"
  mean different things to different readers — including AI models. Replace each with
  something you can measure.
- **Write explicit "do NOT" lines.** Telling an agent what isn't its job is the single
  most effective way to stop it wandering outside its role.
