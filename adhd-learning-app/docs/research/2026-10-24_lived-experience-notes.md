# Lived experience — direct input, 2026-10-24

Recorded verbatim-in-substance, from conversation, as evidence for the
self-regulation gap already named in
`docs/inherited-research/research/2026-08-13_learning-how-to-learn.md`.

- Writes notes but does not go back to review them — a write-and-abandon
  pattern, not a retrieval-practice pattern.
- No existing study method for retaining information.
- Does not know what note-taking technique actually works for him.
- Did not learn how to learn as a child; still teaching himself how to learn
  now, as an adult.
- Likes writing, writes a lot — but writing volume is not the same skill as
  knowing how to study or learn from what was written.

## Why this matters for the product

This is direct, first-person confirmation of the gap the Aug 13 research
already flagged architecturally: the locked design (universal layer + ADHD
supports + router) assumes notes already exist and need scheduling. It does
not address what's described here — notes get written and then abandoned,
because the skill that's missing isn't content delivery, it's knowing how to
go back, review, and retain.

This directly supports two scope items already proposed in this brainstorm,
not yet locked:
1. The self-regulation layer (plan → monitor → reflect), proposed
   2026-08-13, never signed off in `DECISIONS.md`.
2. Note-taking coaching — the system assessing *how* notes are taken, not
   just converting them — which has no prior research in this project at
   all; it is new scope, not an inherited mechanism.
