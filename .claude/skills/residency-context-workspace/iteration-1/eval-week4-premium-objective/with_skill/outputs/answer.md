## Week 4 Premium Residency Objective

No, you don't need to go back to the ADHD budgeting app. Week 4 is the exception to the specialization pattern: **"This week you are building the same thing as Standard Residency students."** Unlike Weeks 2/3/7, Week 4 is *not* specialization-specific — everyone, Premium and Standard alike, builds the same thing:

**Build an AI Chatbot for Career Coaching** — a chatbot that helps people learn about career paths and requirements, using the U.S. Department of Labor O*NET dataset as a "Closed RAG" data source (internal data, not open internet). Hosted on Vercel + Supabase, with AI agents integrated via OpenRouter.

So the ADHD app only ever applied to the Standard track's Week 3 challenge — your Week 3 specialization app (the caregiving-coordinator app) was the correct Premium path for that week. Week 4 is a fresh, separate challenge that applies to everyone the same way; it's not something you build on top of or revert to the ADHD app for.

Key requirements for Week 4:
1. Write new product requirements (vision/scope/technical) for this chatbot app, using Week 2 templates, in a Notion doc.
2. Add specs to your kanban board.
3. New GitHub repo named "Week 4 Web App."
4. Host on Vercel + Supabase.
5. Get all O*NET data into the app.
6. Design and integrate AI agents for the chatbot via OpenRouter.
7. Make the chatbot functional, test it, and refine it.
8. Write a one-page summary (not AI-written) of what you did and learned.

Deliverables: Supabase DB architecture diagram, GitHub repo link, live Vercel link.
