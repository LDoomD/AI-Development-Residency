## Submission Guidelines

When you submit, you must submit on the Tech Fleet Network Platform under your appropriate weekly module on Courses.

### Instructions to Upload Homework on Github

1. Login to your Github account
2. Login to Claude Desktop
3. Fill out the submission template (see below)
4. Ask Claude to create a new folder in your repository
5. Name the folder "Week [ number ] Coding Challenge". For example, "Week 3 Coding Challenge"
6. Drop all of the code that you worked on within that folder for the week. This helps you keep your Github organized.
7. Ask Claude to put the submission document into the same folder
8. Create a pull request on your Github with the change
9. Merge the Pull Request
10. Share the Github repository link with me

## How to Submit

Email your teacher the submission template with the information filled out to mdenner@techfleet.org
