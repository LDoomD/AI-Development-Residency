# Week 3 Coding Challenge — Host a Web App for ADHD People to Budget

## How to Submit

Email the teacher the link to your Github repository: mdenner@techfleet.org

## Summary

Now it's time to build and ship! Your product requirements from Week 2 are going to become a reality with Claude Code. You will create a web server, a database server, and the code to make the app a reality.

## Standard Residency Objective

Take the product specifications made in Week 2 and build the ADHD Budgeting App. Host on Vercel. Use Material UI for components.

## Premium Residency Objective

**You are not building an app for people with ADHD to budget — you are building the app you chose based on your specialization.** Build that using these same tools and the product specifications you made.

## Tools

Claude Code, Material UI, Vercel, Supabase

## Deliverables

1. Database architecture diagram from Supabase
2. Github repository
3. Vercel link with the live app

## Requirements

1. Take your product requirements from Week 2 homework and start building the app with Claude Code. Build your application to spec.
2. Create a ticket in the backlog with your documented requirements and put it into the proper status on the kanban board as you work on it.
3. Create a new Github Repository called "Week 3 Web App".
4. Host the app on Vercel.
5. Set up Supabase and drop your database code into Supabase.
6. Use Material UI for the interface design components.
7. Write a one page summary (NOT USING AI) of what you did and what you learned when you submit the work to me.

## To Submit

CREATE A NEW GITHUB REPOSITORY AND NAME IT "AI DEVELOPMENT RESIDENCY - WEEK 3 - APP"

Use the submission template.

Push all of the coding files and the submission template files you produce into the repository within through a merge.

Add the submission template file into the repository as a separate file from the code anywhere in the repository.

Email the instructor the following:
1. The link to the Github repository
2. The link to the Vercel website URL
