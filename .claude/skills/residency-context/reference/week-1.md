## Overview

The lecture explains how to build useful, reliable products by combining design, research, planning, and software development. Quick AI-made prototypes can help test ideas, but products for real users need careful work on security, quality, and user needs. Teams should set goals, test ideas early, release improvements in small steps, and use feedback to guide what comes next. The class also covers key skills such as user experience, product management, and the basics of how websites, servers, databases, and AI tools work. Keep learning and use your own judgment instead of trusting every AI result.

## Objectives

1. Distinguish "vibe coding" from enterprise AI development, and understand when each is appropriate.
2. Explain the facets of user experience and product management being taught in the class.
3. Explain how to keep your brain power while using AI tools.
4. Describe the agile product development lifecycle.
5. Explain iterative release cycle approaches for MVP and MMP.
6. Compare agile and waterfall approaches to research, collaboration, planning, and delivery.
7. Describe basic two-tier and three-tier network architectures.
8. Understand how the web works.
9. Understand how Claude Desktop is structured with AI skills and files.

# Week 1 Coding Challenge — Github and Claude Code Skills Development

## How to Submit

Email the teacher the link to your Github repository: mdenner@techfleet.org. Use the submission template. Push the skills files and submission template into the repository's "Week 1" folder.

## Summary

How does AI remember? Well, it doesn't remember anything by default! If you want an AI model to do what you want in proper ways, you need to make it remember what to do, why, and how. This is where you as an AI Developer come in: you create your own content called Skills to ensure your AI model remembers what, why, and how. This is fundamental to building enterprise-ready applications consistently.

## Objective

Build a brain for your Claude to understand how to properly do 5 things needed for strong enterprise-level development. Research what those are, pick 5 to focus on, develop the skills content with Claude, and drop it into Claude where it goes so your AI model can actually use it.

## Tools

Claude Desktop, Github

## Requirements

1. Setup Claude Desktop — get your Claude seat from Tech Fleet, download Claude Desktop
2. Create a Github account
3. Connect your Github account to Claude Desktop
4. Create your first repository and name it: "Week 1 Claude Skills"
5. Create the Skills files and folders for your repository and your Claude
   - Research AI skills on the internet: how you get AI to do the same thing properly over and over
   - Research 3 deep topics that make great enterprise-ready software: UX, Accessibility, Security, Other stuff
6. Implement new skills file and folder content into your Claude Code environment's memory
7. Enforce the skills to start when Claude starts up every agent session
8. Merge your skills files into the Repository on Github
9. Test your skills in Claude to ensure Claude has access to the new content when starting a new Agent
10. Write a one page summary (NOT USING AI) of what you did and what you learned when you submit the work: what topics did you choose? what makes a good skill document? how did you approach it? how did you ensure it's quality enough?

1. Go to https://github.com, create an account, finish registering
2. Go to "Repositories" section, create new Repository, name it **"AI Development Residency"**
3. Then on your computer: open Claude Desktop → Claude Code → new session
4. **"CHANGE THE AI MODEL TO CLAUDE 4.8 - MEDIUM EFFORT. Other models are not as good with coding, and they eat way more credits faster! 4.8 beats coding performance still to this day. Always use 4.8 in this class."** — flagged, not acted on; this may predate models actually available now. Each student's own call whether to follow it.
5. Tell Claude Code you want to set up this computer for coding in a Github repository, give it the link, have it teach you the process (**do not have it do it for you without teaching you**)
6. Choose a folder with lots of disk space and have Claude set up work there
7. Follow all the steps Claude teaches

## What Does Good Homework Look Like?

1. The GitHub repository contains three skill files, focused on topics such as UX, accessibility, security, or other important enterprise-development topics the student chooses.
2. The skills are dropped into the proper place on the student's computer where Claude can use them.
3. Claude can use the skills in a new Claude session, and the student has checked that they load.
4. The skill files and completed submission template are in the repository's Week 1 folder.
5. The student has written the required one-page submission summary (not using AI).
6. The student has emailed the instructor the repository link.
