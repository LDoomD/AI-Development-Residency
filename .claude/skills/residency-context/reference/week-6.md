## How to Submit

## Summary

To make applications that last you need to code for performance, efficiency, scalability, and security. Enterprise architecture involves decisions that teams make to best suit the problems they are trying to solve. In this coding challenge you will make your own enterprise architecture decisions and perform research to identify the best way to go.

## Standard Residency Objective

Take your code base from week 3 or 4 and create an enterprise-ready version of the app. You must define what that means! Anything you decide must be documented in ADR's. Upload the ADR's to your repo. Create CI/CD checks on your Github repo to ensure that regressions never happen whenever new code gets added.
