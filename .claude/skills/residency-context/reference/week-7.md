## How to Submit

## Summary

Now it's time to make your app talk with different apps! API integrations are a common way to pull data from other apps and present the data in a way you need to customize. In this challenge you will take your existing Week 3 repo and integrate an API library into the code, and build an elegant experience around it.

## Standard Residency Objective

Choose one of the following API Libraries below and implement it into your ADHD Budgeting App however you see fit. Make sure that the experience you build is valuable, feasible, and usable for people who experience ADHD. Document your architectural decisions in ADR's, and complete a PenTest Report.

1. Nilearn ADHD API - integrate lessons about ADHD
2. Google Chat API - integrate a user-to-user chat function
3. Financial Budgeting API - integrate more nuanced financial budgeting features
4. OpenRouter API - make your application agentic somehow
