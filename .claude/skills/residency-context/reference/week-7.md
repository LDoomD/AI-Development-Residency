# Week 4 Coding Challenge — Build an AI Chatbot for Career Coaching

## How to Submit

Email your teacher the link to your Github repository: mdenner@techfleet.org

## Summary

These days, agent-based applications are everywhere. You should learn how to build apps that use AI agents, and also when it's better NOT to use an agent but to use your own data instead. This exercise will help you engineer a combination of both: an experience that lets someone chat with an AI chat bot that utilizes what's called a "Closed RAG" system: data coming from internal sources instead of the internet.

## Standard Residency Objective

Create an AI Chatbot that helps people learn about possible career paths and requirements for careers. Use the U.S. Department Of Labor O*NET Dataset for all of the data related to careers. Host the app on Vercel and Supabase.

## Premium Residency Objective

**This week you are building the same thing as Standard Residency students.** (Unlike Weeks 2/3/7, this week is not specialization-specific — everyone builds the same career-coaching chatbot.)

## Tools

Claude Code, O*NET Data Set, OpenRouter, Github, Vercel, Supabase

## Deliverables

1. Your database architecture diagram from Supabase
2. Your Github repository
3. Your Vercel link with the live app

## Requirements

1. Make new product requirements (only vision and scope and technical requirements) for this application. Use the Week 2 templates for guidance on what to write. Put it in a Notion document.
2. Add the specifications to your kanban board and put the ticket into the proper status.
3. Create a new Github Repository called "Week 4 Web App".
4. Host the app on Vercel and Supabase.
5. Get all of the O*NET data into your app somehow.
6. Figure out how you're going to use AI agents for your chat bot.
7. Integrate your AI agents with the app using OpenRouter.
8. Make the chatbot functional.
9. Test the chat bot and refine it based on what you find that you think needs to be fixed.
10. Write a one page summary (NOT USING AI) of what you did and what you learned when you submit the work to me.
