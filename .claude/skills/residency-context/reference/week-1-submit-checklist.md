# Objective

Build a brain for your Claude to understand how to properly do 5 things that are needed for strong enterprise-level development. You research what those are in Claude, you pick which 5 you want to focus on, and then you develop the skills content with Claude,. Drop it into Claude in the place where it goes so your AI model can actually use it.

# Requirements

1. Setup Claude Desktop

   1. Get your Claude seat from Tech Fleet
   2. Download Claude Desktop
   3. Create a Github account
   4. Connect your Github account to Claude Desktop
   5. Create your first repository and name it: “Week 1 Claude Skills”
2. Create the Skills files and folders for your repository and your Claude

   1. Research AI skills on the internet: how you get AI to do the same thing properly over and over.
   2. Research 3 deep topics that make great enterprise-ready software.
      1. UX
      2. Accessibility
      3. Security
      4. Other stuff
   3. Implement new skills file and folder content into your Claude Code environment’s memory.
   4. Enforce the skills to start when Claude starts up every agent session
   5. Merge your skills files into the Repository on Github
   6. Test your skills in Claude to ensure that Claude has access to the new content you made when starting a new Agent.
3. Write a one page summary **(NOT USING AI)** of what you did and what you learned when you submit the work to me. What topics did you choose? What makes a good skill document? How did you approach it? How did you ensure it’s quality enough?

# What Does Good Homework Look Like?

1. The GitHub repository contains three skill files, focused on topics such as user experience, accessibility, security, or whatever the student chooses for important topics for enterprise development.
2. The skills have been dropped into the proper place on the student’s computer where Claude can use them.
3. Claude can use the skills in a new Claude session, and the student has checked that they load.
4. The skill files and completed submission template are in the repository’s **Week 1** folder.
5. The student has written the required one-page submission summary about what they did and learned, without using AI.
6. The student has emailed the instructor the repository link.
