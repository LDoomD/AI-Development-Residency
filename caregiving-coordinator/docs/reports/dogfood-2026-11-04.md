## 1. What dog feeding is (from the teacher's board, "Steps to Produce Literally Anything", Figma node 2390:7831)

- **Each new document is made from the ones you already checked.** Research leads to the vision, the vision leads to the scope, and so on.
- **Claude doesn't remember other chats.** It only knows what's in the current chat (its "context"). So the work lives in saved documents, and each new chat gets those documents.
- **Why it works:**
  - You never start over.
  - Claude uses your documents instead of guessing.
  - It uses fewer tokens.
  - It stops "drift" (Claude slowly changing what you already decided).
  - You make every choice, so you understand your own product.

**The 11 steps:**
1. Write the idea in your own words.
2. Ask Claude where to start.
3. Make the first document and save it as markdown.
4. Open a new chat and give it every saved document, plus the template for the next thing.
5. Ask Claude to read everything first.
6. Work on one part at a time.
7. Ask where each answer came from (your documents, not the internet).
8. Find mistakes and fix them, in plain words.
9. When stuck, ask Claude to teach you. Claude gives the facts, you make the choice.
10. Approve the work and save it as a new markdown file (a new version, never overwritten).
11. Give the new document to Claude and go back to step 4.
