# Market research, Prompt 2 results (channels, competitors, size, CAGR)

Written 2026-11-01. One section per segment from the Prompt 1 top 10. Method: teacher's market-research definition (segments, size, opportunity). Every claim is tagged with an evidence state (`documented`, `reported`, `inferred`, `not-assessed`) following the `skeptical-audit` skill. No product is suggested here.

Source quality note: most sources are vendor pages, aggregator profiles and market-report summaries. Where only one source exists it says "single source". Where sources disagree, both numbers are shown.
