# Evidence for each use case, by source (2026-11-02)

For each of the 18 use cases: how often it came up in our forum threads, whether the AARP/NAC 2025 report shows something related (with the page), whether the app reviews do (192 caregiving-only problem reviews), and whether the ten competitor rows already cover it. "None found" means we looked and did not find it in what we extracted; it does not prove it is not true. Audience 1 = adult child caring for a parent (55 threads); Audience 2 = spouse or partner (54 threads). Related figures are not always about the same thing as the use case; read them as corroboration, not proof.
