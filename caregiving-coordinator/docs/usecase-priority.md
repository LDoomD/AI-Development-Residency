# Use case prioritization (draft, 2026-11-02)

Placed on the effort and value matrix in the audience workshop board ("Prioritize Use Cases"). **Draft for the owner to move; prioritizing is the owner's judgment call.**

**Value rule (from the research):** high if the problem came up in 8 or more of that audience's forum threads (about 15% or more), low if fewer. This measures how common it is, not how much it matters to the person. Counts: `docs/sources/forum-relevance/usecase-themes-final.json`.

**Effort rule (a rough guess, not from the research):** low if improving it mostly depends on information the caregiver or household already has; high if it depends on relatives, doctors, institutions or aides changing.

**Borderline:** Audience 1 "Medicines, eating, personal care" (8 threads) and Audience 2 "Aides, hospice, trusting others" (8 threads) sit exactly at the value line.
