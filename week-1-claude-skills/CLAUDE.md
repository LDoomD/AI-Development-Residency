# Week 1 Claude Skills

This folder holds project skills in `.claude/skills/`.

## Skills to use

- `project-prd-brainstorm`: use it at the start of any new project, or whenever
  the user wants to brainstorm an idea, plan an app, or write a PRD
  (product requirements document).
  - Start by following that skill. Do not begin by writing code.
  - Ask one question at a time.
  - Save the finished PRD to `docs/PRD.md` only after the user approves it.

## Rules for this folder

- Never write or edit the user's homework summary. They write it themselves.
